Employee Management System — Project Description
A simple Employee Management System built with HTML, CSS, and Vanilla JavaScript.

Features:
Add, edit, and delete employee records

Manage employee name, department, email, and role

Local data storage using browser localStorage

CSV export functionality for easy data backup

Live search and filtering by name or department

Responsive, modern UI using Glassmorphism design

Technologies used:
HTML5

CSS3 (Flexbox, Responsive Design)

Vanilla JavaScript

Browser localStorage

CSV export

Live Link: https://senones.github.io/Employee-Managment/
